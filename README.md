# skills-cheets

> Claude 스킬(Skills)을 업무에 바로 쓰기 위한 **사용 가이드·표준·템플릿 모음**
> 스킬별로 "언제 쓰는지 → 무엇을 준비하는지 → 어떻게 요청하는지 → 결과를 어떻게 점검하는지"를 한 폴더에 정리

## 스킬 목록

| 스킬 | 용도 | 가이드 | 상태 |
| --- | --- | --- | --- |
| `ppt-master` | 편집 가능한 네이티브 PPTX 제안서·보고서 생성 | [ppt-master/](ppt-master/README.md) | v1.0 |
| _(추가 예정)_ | | | |

## 폴더 구조

```text
skills-cheets/
├── README.md                 # 이 문서 (스킬 목록·사용 규칙)
├── CONTRIBUTING.md           # 스킬 가이드 추가·수정 규칙
├── _template/                # 새 스킬 가이드 작성용 템플릿
│   └── README.md
└── ppt-master/
    ├── README.md             # 스킬 가이드 (개요·준비물·요청 방법·점검·문제 해결)
    ├── prompts.md            # 바로 복사해 쓰는 요청 문구 모음
    ├── standards/            # 업무 무관 공통 표준 (거의 바뀌지 않음)
    │   └── PPT-MASTER_생성표준.md
    └── templates/            # 업무마다 복사해서 채우는 양식
        └── YYYYMMDD_고객명_PPT구성.md
```

## 공통 사용 원칙

1. **표준 + 업무 문서 2단 구조**: 업무와 무관한 규칙은 `standards/`, 고객·내용은 `templates/`를 복사해 작성
2. **문서는 첨부, 요청은 짧게**: 두 문서를 Claude에 첨부하고 한 줄로 요청 (예시는 각 스킬 `prompts.md`)
3. **사실은 입력 자료로만**: 자료에 없는 수치·사례는 `[자료 필요]`로 남기게 하고 사람이 채움
4. **고객 자료는 레포에 올리지 않음**: 레포에는 표준·템플릿·가상 예시만, 실제 고객 구성 문서·산출물은 업무 저장소에 보관

## Claude에서 스킬 쓰는 방법 (공통)

- claude.ai 설정의 Skills 항목에서 해당 스킬 활성화 여부 확인 (조직 스킬은 관리자 배포 필요)
- 요청할 때 스킬 이름을 직접 언급하면 확실하게 호출 (예: "ppt-master 스킬로 …")
- 결과물은 대화창 파일 카드에서 다운로드, 필요한 경우 데스크톱 앱에 폴더 연결 후 저장 위치 지정
