# 프로필: 내부 브리핑

> 팀장·임원 대상 **1~5장 짧은 내부 보고**용 프로필
> 아래 표는 공통 표준에서 **바꾸는 값**, 표에 없는 항목은 공통 표준 그대로
> 상태: v0.1 초안 — 팀 검토 후 확정

| 항목 | 공통 표준 | 이 프로필 | 이유 |
| --- | --- | --- | --- |
| 청중 | 고객사 | 사내 팀장·임원 | |
| 목적 | 고객 결정 | 현황 공유 + 내부 의사결정 (승인·지원 요청) | |
| 사용 방식 기본값 | 구성 문서 지정 | 겸용 | 보고 후 메일로 전달 |
| 발표자 노트 기본값 | 사용 방식 따라 | 미작성 | 짧은 덱, 장표로 완결 |
| 장수 | 구성 문서 기준 | **1~5장** (표지 생략 가능, 1장이면 표지 없음) | 짧게 |
| 장표 흐름 | SCR 전체 | 결론·요청 → 근거 → (선택) 상세 | 임원 보고는 결론을 첫 장에 |
| 첫 장 | 표지 | **요약 장**: 핵심 메시지 + KPI 박스 최대 3개 + 요청 사항 | 첫 장만 보고 결정 가능 |
| 상단 트래커 | 사용 | 3장 이하 덱은 생략 | 장수가 적어 불필요 |
| 하단 바 보안 표기 | 구성 문서 지정 시 | 기본 `사내 한정` | 내부 자료 |
| 스토리라인 사전 확인 | 실행 절차 3단계 | 생략 (요청 시에만) | 짧은 덱은 바로 생성이 효율적 |
| 구성 문서 | 필수 항목 12개 | 간이 입력 허용: 청중, 목적·요청, 핵심 메시지, 근거 자료 4개만 있으면 진행 | 작성 부담 축소 |
