# ppt-master 요청 문구 모음

> 오버레이 스킬 사용 시 표준 첨부·스킬명 대신 `ppt-proposal` / `ppt-report` / `ppt-briefing` 으로 바꿔 사용

> 표준 문서와 구성 문서를 **첨부한 상태**에서 사용, `{ }` 부분만 바꿔서 복사

## 1. 기본 생성

```text
ppt-master 스킬로, PPT-MASTER.md 표준에 따라
{YYYYMMDD_고객명_PPT구성.md} 내용으로 PPT 생성해줘.
```

## 2. 스토리라인 먼저 (권장)

```text
ppt-master 스킬로 PPT-MASTER.md 표준과 {구성 문서} 기준
스토리라인 표(장표별 제목·핵심 메시지 줄·본문 요소)만 먼저 작성해줘.
장표는 아직 만들지 말고, [자료 필요]·[확인 필요] 목록도 같이 줘.
```

이어서:

```text
스토리라인 확정. {수정 사항이 있으면 기재} 반영해서 PPT 생성 진행해줘.
```

## 3. 빠른 초안

```text
ppt-master 스킬로 빠르게 초안 만들어줘. 중간 확인 없이 진행.
표준: PPT-MASTER.md / 내용: {구성 문서}
```

## 4. 장표 단위 수정

```text
{5}장 수정:
- {구성도의 DB 영역을 오른쪽 영역으로 이동}
- {연결선 교차 제거}
다른 장표는 변경하지 말 것.
```

```text
{3}장 텍스트 넘침 — 폰트 축소 말고 문장 압축으로 해결해줘.
```

## 5. 기존 PPTX 활용

```text
ppt-master 스킬로 첨부한 {기존.pptx}를 PPT-MASTER.md 디자인 표준에 맞게 리디자인해줘.
내용·수치는 그대로 유지, 장표 구성은 바꾸지 말 것.
```

```text
ppt-master 스킬로 첨부한 {템플릿.pptx}의 마스터를 사용해서 {구성 문서} 내용 채워줘.
```

## 6. 버전 업

```text
첨부한 {v1.0 pptx}와 변경된 {구성 문서} 비교해서 바뀐 장표만 수정한 v1.1 만들어줘.
변경 장표 목록도 같이 줘.
```

## 7. 최종 점검만

```text
첨부한 {pptx}를 PPT-MASTER.md 10장 완료 전 점검표 기준으로 점검하고
위반 항목을 장표 번호별로 정리해줘. 수정은 하지 말 것.
```
